# 📝 Flask Blog Users

A full-stack multi-user blogging platform built with **Python**, **Flask**, **Jinja2**, **SQLAlchemy**, and **SQLite**. Users can register, log in securely, create blog posts, edit or delete their own posts, and explore articles published by other users.

---

## 🚀 Features

- User Registration & Login
- Secure Password Hashing
- User Authentication & Session Management
- Create, Read, Update & Delete (CRUD) Blog Posts
- User Authorization (Users can edit/delete only their own posts)
- Responsive User Interface
- Dynamic HTML Rendering using Jinja2
- SQLite Database with SQLAlchemy ORM
- Flash Messages for User Feedback
- Clean and Modular Flask Project Structure

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Yuktamahajan1999/Blog_users.git
```

### Navigate into the project

```bash
cd Blog_users
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Mac/Linux

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000/
```
